# 采购风险工作台 UI

入口 `/workbench/`，现有报告及归档页导航增加工作台链接；根路径继续保留最新报告，避免破坏旧链接。

采用用户确认的暖白、象牙白、深蓝样式；左侧导航、概览条、采购批次表、详情、右侧事项与资金、报告入口。保留现有 Arbor 字标并配 Scivor 文本，不将生成预览图中的新树形图标当成正式品牌资产。

筛选、搜索、批次选择、详情预览可以本地交互；预测验证与报告跳转到现有页面。全部金额、批次和日期为固定合成演示。模拟预览不调用账户数据库；尚未提供账户执行或真实数据编辑。界面不提供无效的设置、语言切换或操作历史按钮。

CSS 提供桌面、平板、手机断点；表格允许区域内横向滚动，移动端导航转为顶部横排。支持键盘焦点、输入标签、按钮展开状态和减少动态效果。最终桌面及移动截图验收尚待可连接的浏览器环境。
